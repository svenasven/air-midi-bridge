# Contributing

Please report the mixer model, firmware, application version, MIDI device and
mode, connection type, relevant mapping and reproduction steps. Remove private
IP addresses and personal profile names before posting logs.

Model recognition is not proof of hardware compatibility. New protocol families
need their own address mapping, value ranges and verification on physical hardware.
Do not add a model to the supported list merely because it responds to OSC.

Run build.ps1, then --ui-test for interface changes. Keep live writes disabled in
automated tests. Keep XML protocol keys language-independent.
